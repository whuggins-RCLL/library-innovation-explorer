Design playground

A page with nothing important on it. Redesign it, break it, or delete it — the rest of the site does not depend on anything here.

What this page is for

Design changes are easier to judge when you are not also worried about breaking something. This page holds a few plain, unremarkable pieces — headings, buttons, a card, some tags, an input — so you have somewhere to try ideas out.

One thing worth knowing: this page shares styles.css with the rest of the site. So if you change a shared style here, such as a color variable or the look of every button, the home page changes too. That is often exactly what you want. If you would rather keep an experiment contained, ask your agent to scope the new styles to this page only.

Things to try here

  • Change the color variables at the top of styles.css.
  • Make the type scale more dramatic — bigger headings, smaller body text.
  • Give the buttons a different shape, weight, or hover behavior.
  • Lay the sample pieces out in a grid instead of a stack.
  • Try a version with much more white space, then one with much less.
  • Rebuild this page from scratch in whatever way you prefer.
