Make it yours

This page is part of the starter, and it is about the starter. It exists to talk you out of treating this project as a finished site about libraries.

This is a template, not a subject

The cards on the home page describe areas of library work. That is example content. None of the code knows or cares what the cards are about — it reads a list from data.js and draws whatever it finds there.

So the topic is yours to choose. The same six cards, the same filters, and the same challenge button work just as well for a collection of museum objects, the services one department offers, the stages of a grant process, a reading list, the systems your team maintains, or something nobody has built a page for yet.

If the site still says "library" everywhere by the end of the workshop, you have probably not pushed it far enough.

How to use the prompts below

  1. Pick one small change. Not three. One change is something you can actually check.
  2. Copy a prompt and fill in the blanks. Anything in <ANGLE BRACKETS> is yours to replace.
  3. Read what the agent says it did. Then look at the page yourself. These are not the same thing.
  4. Save it, then pick the next one. Small commits are easy to undo. Large ones are not.

Notice what almost every prompt here has in common: it says what to do, and it says what to leave alone. Setting limits is most of the skill.
